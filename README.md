
## Warehouse Robot Simulation

This repository contains files regarding a simulation of an automated warehouse with a grid layout and different types of mobile robots.

## Current Features

- Grid-based warehouse environment
- Configurable warehouse dimensions
- Shelves and obstacles
- Different robot types with individual properties
- Robot movement and collision detection

## Project Structure

- `main.py` – Main program and simulation setup
- `warehouse.py` – Warehouse grid, tiles, and collision detection
- `robots.py` – Robot classes and movement logic

## Technologies

- Python 3

## Status

The project is currently under development. More features, such as path planning, task management, and warehouse visualization, may be added in future versions.
